# East Africa Health Outcomes and Spending Dashboard

## Project Overview
This project analyses health outcomes and healthcare spending across nine East African countries using Power BI and World Bank data.

The dashboard helps users compare health indicators across countries and years, identify patterns and explore differences in healthcare performance.

## Objectives
- Compare child and maternal health outcomes.
- Analyse immunisation coverage.
- Examine the distribution of health workforce indicators.
- Explore healthcare spending across countries.
- Identify changes in health indicators over time.

## Tools and Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel / CSV
- World Bank Health Nutrition and Population Statistics

## Data Source
World Bank – Health Nutrition and Population Statistics.

## Limitations
